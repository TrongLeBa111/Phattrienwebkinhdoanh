# 👥 PHÂN CHIA VAI TRÒ & TRÁCH NHIỆM

> Dự án gồm **5 thành viên**, mỗi người đảm nhận một vai trò chính.  
> Tuy nhiên, tất cả đều tham gia brainstorm chung ở giai đoạn đầu.

---

## 1️⃣ BA / Product Manager (PM)

**Thành viên:** `[Điền tên]`

**Trách nhiệm chính:**
- Định hình vấn đề (pain point) của người dùng
- Phân tích tính năng từ 3 vai trò: User / Business / Technical
- Lên kế hoạch các giai đoạn dự án
- Viết phần "Phân tích" và điều phối báo cáo cuối

**Kỹ năng yêu cầu:**
- Phân tích nghiệp vụ
- Giao tiếp & điều phối nhóm
- Tư duy sản phẩm (product thinking)
- Kỹ năng viết lách

---

## 2️⃣ Backend / System Architect

**Thành viên:** `[Điền tên]`

**Trách nhiệm chính:**
- Thiết kế ERD / Database schema
- Xác định API endpoints
- Xử lý logic phức tạp (Image Search, address 1-N)
- Viết code backend demo

**Kỹ năng yêu cầu:**
- Database design (normalization, indexing)
- REST API / GraphQL
- Node.js hoặc Python
- SQL

---

## 3️⃣ Frontend Developer

**Thành viên:** `[Điền tên]`

**Trách nhiệm chính:**
- Chuyển đổi thiết kế Figma thành code UI
- Tích hợp API từ backend
- Xử lý state management & logic UI
- Testing UX flow

**Kỹ năng yêu cầu:**
- React / Next.js
- HTML / CSS / JavaScript
- UI Component & State Management
- API integration (Axios)

---

## 4️⃣ Designer / Figma

**Thành viên:** `[Điền tên]`

**Trách nhiệm chính:**
- Wireframe (Low-fi) & High-fidelity Design
- Prototype với micro-interactions
- Đảm bảo consistency của Design System
- Thu thập feedback và cải tiến UX

**Kỹ năng yêu cầu:**
- Figma (nâng cao: auto-layout, components, variants)
- UX/UI principles
- Prototyping & user testing
- Design thinking

---

## 5️⃣ QA / Tester & Cộng tác

**Thành viên:** `[Điền tên]`

**Trách nhiệm chính:**
- Kiểm thử toàn bộ flow và edge cases
- Vẽ BPMN & Use Case diagram (Draw.io)
- Hỗ trợ viết phần Testing trong báo cáo
- Báo cáo lỗi và đề xuất cải tiến

**Kỹ năng yêu cầu:**
- Testing mindset (happy path + exception)
- Draw.io (BPMN / UML)
- Use case analysis
- Chỉ ra lỗi & đề xuất giải pháp

## 📌 Lưu ý phân công

>
