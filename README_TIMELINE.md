# 📅 TIMELINE & MILESTONE

| Tuần | Giai đoạn | Deliverable chính | Trạng thái |
|------|-----------|-------------------|------------|
| 1–2 | Phân tích & Lựa chọn | Feature Matrix, Pain Point Analysis | ✅ Complete |
| 3–4 | Phân tích Tính năng | 3-role Feature Analysis | ✅ Complete |
| 5–7 | Design & Diagrams | BPMN, Use Case, ERD, Figma Hi-Fi | 🔄 In Progress |

---

## 🗓️ Chi tiết theo tuần

### Tuần 1–2: Phân tích & Chọn Lĩnh vực
- Brainstorm toàn nhóm
- BA/PM viết "Phân tích lĩnh vực" (pain point, scope)
- Chọn: Thời trang High-end **hoặc** Nội thất thông minh
- **Output:** Document phân tích, quyết định lĩnh vực

### Tuần 3–4: Phân tích Tính năng 3 Vai trò
- BA/PM dẫn dắt Feature Matrix
- Xác định breakthrough features: Visual Search, Quick Edit Cart, Smart Address
- QA lập test scenarios ban đầu
- **Output:** Feature Analysis Matrix (bảng 3 vai trò)

### Tuần 5–7: Thiết kế & Diagrams *(Giai đoạn quan trọng nhất)*
- Backend + QA: Vẽ BPMN, Use Case, ERD trên Draw.io
- Designer: Wireframe (Low-fi) tuần 5-6 → Hi-Fi + Prototype tuần 6-7
- Frontend: Review Figma, lên danh sách component
- BA/PM: Review & approve tất cả diagrams
- **Output:** 3 file Draw.io + Figma file hoàn chỉnh

### Tuần 8–10: Implementation & Integration
- Backend: Setup DB, code API endpoints (≥10), tích hợp image recognition
- Frontend: Setup React, build ≥8 components, integrate API
- Designer: Hand off design spec, QA implementation
- QA: Testing flows, bug reporting
- **Output:** GitHub repos (backend + frontend), live demo localhost

### Tuần 11–12: Testing & Báo cáo
- Mỗi thành viên viết phần báo cáo tương ứng vai trò
- BA/PM tổng hợp và hoàn thiện báo cáo
- QA: Final testing, viết test report
- **Output:** Báo cáo PDF hoàn chỉnh (20–30 trang), slide thuyết trình
